# Prompt 01 — Crear el esqueleto del proyecto

Leé `AGENTS.md` y toda la documentación de `docs/` antes de actuar.

Quiero implementar únicamente la Fase 0 de `docs/IMPLEMENTATION_PLAN.md`.

Antes de modificar:
1. Presentá un plan breve.
2. Indicá las versiones de Android Gradle Plugin, Gradle, Kotlin, Compose y SDK que proponés, verificando compatibilidad con documentación oficial actual.
3. Indicá qué herramientas o versiones del entorno no podés verificar.

Después:
- Crear un proyecto Android nativo Kotlin + Jetpack Compose.
- Mantener un único módulo `app`.
- Configurar navegación mínima y una pantalla inicial placeholder.
- Configurar pruebas unitarias básicas.
- No añadir Room, GPS, mapas, backup ni otras funciones de fases posteriores.
- No agregar backend, autenticación, telemetría ni publicidad.

Al terminar, ejecutar build y pruebas disponibles, enumerar archivos creados y reportar los resultados reales. No afirmar que compila si no se ejecutó la compilación.
